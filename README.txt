EXECUTIVE COMMAND CENTER PWA — STARTER V0.1

This is a mobile-first setup-wizard prototype with preferences saved in the browser, setup choices for Google email/calendar/Drive, task-system selection, and a dashboard preview.

IMPORTANT:
- No service is connected. These selections do not perform sign-in or authorize APIs.
- AI is deferred. No email is sent.
- Browser local storage is on this device only; clearing browser data may erase preferences.
- A full PWA requires publishing these files to an HTTPS website. Opening index.html as a local file does not enable service-worker installation.
- This starter can be developed with free tools, but free hosting/API limits may apply.
- Never collect Google passwords here. Real integrations require Google's official OAuth flow, least-privilege permissions, and a secure backend. Never put secrets or refresh tokens in frontend files.

Android path: extract ZIP, publish folder to a free HTTPS static host, open URL in Chrome, menu ⋮ > Add to Home screen / Install app.
