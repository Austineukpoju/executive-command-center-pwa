# Executive Command Center

Mobile-first personal workspace prototype for GitHub Pages.

## Important
- This version contains sample emails, sample calendar events, and example files.
- The connection section is a placeholder. It does **not** connect to Gmail, Calendar, or Drive.
- Real Google integrations require Google Cloud OAuth configuration and secure token handling. Never put a client secret or access token in this public repository, and never enter your Google password into this app.
- Tasks are temporary in-browser data and do not sync to an online account.
- AI has been deferred to keep the initial project free.
